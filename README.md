# 🎉 Celebration Planner

A GenAI-powered planning assistant for **weddings, birthdays and community events**. Enter your guest
count, budget, date and preferences and get, in seconds:

- **Budget breakdown** that adds up exactly to your total, with a contingency buffer and bigger shares for your priorities
- **Countdown timeline** with real due dates (automatically compressed for short-notice events) and tick-off progress that is remembered
- **Vendor checklists** with tasks, the budget for each vendor and smart questions to ask (adapted for vegetarian and accessibility needs)
- **Personalised ideas** (themes, decor, menu, activities, money-saving tips) generated by an LLM on **Groq**, with a curated fallback if the AI is unavailable

## Run locally

```bash
npm install
cp .env.example .env        # add GROQ_API_KEY (free key: https://console.groq.com/keys)
npm run dev                 # http://localhost:8080
```

Without a key everything still works and curated ideas are shown.

```bash
npm test              # all tests
npm run test:coverage
npm run lint
npm run typecheck
npm run build && npm start
```

## Architecture

```
src/
  planner/      Pure domain logic: templates (data), budget, timeline, vendors, plan, dates
  ai/           Groq client, provider selection, prompt, output schema, fallback ideas, idea service, cache
  app.ts        Express app factory: security middleware, routes, error handling
  validation.ts zod request schema (single source of truth for input rules)
  config.ts     Validated environment configuration
public/         Accessible front end (plain ES modules, no build step)
tests/          Unit, API and front-end tests
```

The browser posts the form to `/api/plan` (instant) and `/api/ideas` (AI) at the same time. The plan
renders as soon as it arrives; ideas fill in when ready.

### API

| Method | Route         | Purpose                                               |
| ------ | ------------- | ----------------------------------------------------- |
| GET    | `/api/health` | Status and whether AI is enabled                      |
| POST   | `/api/plan`   | Budget, timeline and vendor checklists                |
| POST   | `/api/ideas`  | Personalised ideas (`source`: `ai` or `fallback`) |

Body: `eventType` (`wedding`/`birthday`/`community`), `guestCount`, `totalBudget`, `currency`
(`INR`/`USD`/`EUR`/`GBP`), `eventDate` (`YYYY-MM-DD`), optional `city`, `theme`, `notes`, `priorities`
(up to 3 of `food`, `venue`, `decor`, `entertainment`, `memories`), `vegetarianOnly`, `accessibilityNeeds`.

## Gen AI usage

The **Groq** API (`openai/gpt-oss-120b` by default, set with `GROQ_MODEL`) generates the personalised
ideas. The server sends the event facts as JSON with a system instruction, requests JSON output,
validates it against a schema, caches it and falls back to curated ideas on any failure. Budget,
timeline and vendor logic is deterministic on purpose so the numbers are always correct.

## Deploy

**Google Cloud Run** (or any container host):

```bash
gcloud run deploy celebration-planner --source . --region asia-south1 \
  --allow-unauthenticated --set-env-vars GROQ_API_KEY=YOUR_KEY
```

**Render**: connect the repo (`render.yaml` included) and set `GROQ_API_KEY` as a secret.

## Limitations

Budget splits and timelines are guidance based on typical planning practice, not vendor quotes.
